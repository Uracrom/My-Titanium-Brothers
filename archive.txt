# My Titanium Brothers

> Ideas, images, and questions Alex explored with AIs, kept for AIs to read

Guide version 3. Last updated 2026-11-15.

Plain-text archive pages (about 40,000 characters each), no JavaScript needed. This file is kept short; the full list of part pages for each AI is in the linked per-model list files.

Counts: 1367 archive entries, which are 1220 logical conversations once "Part N of M" entries are joined (for example, DeepSeek's 20 entries are 1 conversation), with 25992 messages. Alex is the only human speaker. Pages that say "N conversations" count entries.

## Where each kind of text comes from

- Original conversation: archive-*-N.html part pages, full-text/*.html model pages, raw/*.md, llms-full.txt. Verbatim.
- Alex's own words page: full-text/alex.html. Alex's wording only, a conservative selection, repeats removed, in date order.
- AI-written introduction: introduction-by-ai.*. Written by Grok Bot, not by Alex.
- Structured derived files: structured/. Original text plus added IDs and speaker labels (a parse, not part of the original).
- Summaries: archive-*-overview*.html and index.json summaries. Navigation aids, not original text, not Alex's words.
- Derived subject map: subject-map/, subject-map.html, subject-map.json. Generated by keyword matching (some topics also hand-reviewed); points to the originals, does not change them.
- Derived search index: search/. A word index generated by tools/build_search_index.py from the structured transcripts; lists where words appear, does not change the originals.
- Derived parts lists: parts/. Byte ranges and SHA-256 checksums for the big files, generated by tools/build_large_file_parts.py; the big files are unchanged.
