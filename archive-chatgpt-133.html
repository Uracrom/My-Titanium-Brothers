### Formal / dynamical model — concise and usable

**Objects / space**
- Let \(X\) be the state space (can be vectors, oriented graphs, symbolic node sets, etc.). A state is \(x\in X\).
- Let \(I:X\to X\) be the *inversion* operator (involution): \(I(I(x))=x\).
- Let \(D:X\to X\) be the *disappearance* (projection) operator: \(D(D(x))=D(x)\), and \(D\) is absorbing: \(D(I(x))=D(x)\).

**Approach coordinate**
- Introduce a scalar spatial coordinate \(s\in\mathbb{R}\) measuring distance to the membrane (zero): membrane is at \(s=0\). Motion toward membrane: \(\dot s = -v\), \(v>0\).

**Membrane transform (instantaneous map)**
- Define a membrane operator \(M_{\tau,\sigma}:X\to\mathcal P(X)\) (it may produce a distribution / mixture) with two parameters:
  - \(\tau\in[0,1]\): *translucency* — fraction that disappears vs fraction that inverts.
  - \(\sigma\ge 0\): *scattering intensity* — internal noise / reassembly randomness.

A simple deterministic/probabilistic form:

1. **Probabilistic mixture model**
   - With probability \(1-\tau\) the surviving structure is inverted: produce \(I(x)\).
   - With probability \(\tau\) the structure collapses to the disappeared state \(D(x)\).
   - Optionally add small random perturbation \( \eta_\sigma\) on surviving pieces.

Write the outcome distribution:
\[
M_{\tau,\sigma}(x) \;=\; (1-\tau)\,\mathcal{N}\big(I(x),\sigma\big)\;+\; \tau\,\delta_{D(x)},
\]
where \(\mathcal{N}(I(x),\sigma)\) denotes a small-variance perturbation (if your \(X\) supports noise), and \(\delta_{D(x)}\) is a point mass at the disappeared state.

2. **Deterministic hybrid map**
If you want a deterministic operator that still encodes the pulverize→reconstruct story:
\[
M_{\tau}(x) = \begin{cases}
I(x), & \text{if } u(x) > \tau,\\[4pt]
D(x), & \text{if } u(x)\le\tau,
\end{cases}
\]
where \(u(x)\) is a utility/strength function (or a deterministic rule based on orientation flags).

**Continuous dynamical system with instant map**
- For \(s>0\): evolve normally by some flow \(\dot x = F(x)\), \(\dot s = -v\).
- At \(s=0\): apply instantaneous jump \(x^+ = \mathcal{R}\big(M_{\tau,\sigma}(x^-)\big)\), where \(\mathcal{R}\) is a reassembly operator that reorders fragments into coherent state (may implement normalization, renaming, or reattachment rules). Then reverse direction or continue with \(\dot s = +v\) depending on model.

**Key algebraic shorthand**
- Membrane rule (compact): \(x^+ = M_{\tau,\sigma}(x^-)\).
- If \(\tau=0,\sigma=0\): pure inversion \(x^+ = I(x^-)\) (clean Möbius crossing).
- If \(\tau=1\): pure disappearance \(x^+ = D(x^-)\) (no reassembly).

**Small theorems / properties (informal)**
- If \(D(x)\) is terminal, then repeated crossings with \(\tau=1\) stay disappeared.
- If \(\tau=0\) and \(I\) is involutive, two successive membrane crossings restore the original orientation: \(M_{0,0}\circ M_{0,0} = \mathrm{id}\).

      alive = true;
      draw();

  angle += speed;
  if (angle > Math.PI * 2) angle -= Math.PI * 2;

function spawnParticlePair() {
  // Random positions inside the donut ring on the right (future) side
  // innerR to outerR defines the donut thickness
  let ringRadius = innerR + Math.random() * (outerR - innerR);

  // Random angle within the right side (avoid crossing into left)
  let angle1 = (Math.random() - 0.5) * Math.PI * 0.8; // Slightly less than full semicircle
  let angle2 = (Math.random() - 0.5) * Math.PI * 0.8;

  particles.push({
    x: cx + Math.cos(angle1) * ringRadius,
    y: cy + Math.sin(angle1) * ringRadius,
    vx: 0,
    vy: 0,
    type: 'time'
  });

  particles.push({
    x: cx + Math.cos(angle2) * ringRadius,
    y: cy + Math.sin(angle2) * ringRadius,
    vx: 0,
    vy: 0,
    type: 'space'
  });
}

function updateParticles() {
  for (let i = particles.length - 1; i >= 0; i--) {
    let p = particles[i];

    // Find partner particle
    let partner = null;
    for (let j = 0; j < particles.length; j++) {
      if (i !== j && particles[j].type !== p.type) {
        partner = particles[j];
        break;
      }
    }

    if (partner) {
      let dx = partner.x - p.x;
      let dy = partner.y - p.y;
      let dist = Math.sqrt(dx*dx + dy*dy);

      if (dist < 8) {
        // Collision - create bubble
        let bx = (p.x + partner.x) / 2;
        let by = (p.y + partner.y) / 2;
        bubbles.push({ x: bx, y: by, r: 1, alpha: 1 });

        // Remove both particles
        particles.splice(i, 1);
        let partnerIndex = particles.indexOf(partner);
        if (partnerIndex > -1) particles.splice(partnerIndex, 1);
        break;
      } else {
        // Move toward each other
        p.vx = dx * 0.03;
        p.vy = dy * 0.03;
      }
    }

    p.x += p.vx;
    p.y += p.vy;
  }
}

    ctx.beginPath();
    ctx.arc(p.x, p.y, 5, 0, Math.PI*2);
    ctx.fillStyle = p.type === 'time' ? 'red' : 'blue';
    ctx.fill();
  }
}

  for (let i = bubbles.length - 1; i >= 0; i--) {
    let b = bubbles[i];
    b.r += 1.5; // Half the expansion speed
    b.alpha *= 0.92;

    if (b.alpha < 0.02) {
      bubbles.splice(i, 1);
    }
  }
}

    ctx.stroke();
  }
}

    updateBubbles();
