Nice screenshot — thanks, that makes the issue obvious. The dot was circling in the center plane (a simple horizontal circle) because in the first 3D snippet I set the tube-angle `v = 0`. That makes the point move **around the torus center** but **not across the tube** — so it looks orthogonal to the torus surface.

Fix: make the tube-angle `v` vary with the main angle `u`. In other words, let the point follow a parametric curve on the torus surface:

x = (R + r·cos(v))·cos(u)
y = r·sin(v)
z = (R + r·cos(v))·sin(u)

and choose `v = k·u` (k controls how the path winds the tube).
- `k = 2` → the dot moves around the tube as it orbits the torus (stays on the surface).
- `k = 0.5` → a Möbius-style half-twist: orientation flips after one revolution.
