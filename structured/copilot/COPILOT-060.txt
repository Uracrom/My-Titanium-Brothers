Great question, Alexandros. For editing large texts with minimal restrictions and some memory capabilities, here are a few standout free tools you might want to explore:

1. **[TextCortex](https://textcortex.com/post/best-free-ai-writing-assistant-tools)** – This one’s particularly strong for long-form content. It offers a browser extension that integrates with platforms like Notion, Gmail, and more. It can paraphrase, expand, and rewrite large chunks of text, and it supports over 70 languages. While it doesn’t have full memory like a human editor, it does let you work across sessions with saved projects.

2. **[Writecream’s Large Text Generator](https://www.writecream.com/large-text-generator/)** – 100% free and no login required. It’s designed for generating and editing long texts quickly. You can input a prompt and get a full-length piece in return. It’s more of a one-shot generator, though, so it doesn’t retain memory between sessions.

3. **[Typefully’s AI Writer](https://typefully.com/tools/ai/ai-writer)** – Also free and no login needed. It’s great for generating full texts and rewriting content. While it doesn’t have long-term memory, it’s fast and flexible for large-scale edits.

4. **[Notion AI](https://comparing.ai/free-ai-writing-asisstants/)** – If you already use Notion, this is a powerful built-in assistant. It’s free with a Notion account and offers unlimited usage. It doesn’t have persistent memory across conversations, but it can handle large documents and keep context within a single workspace.

If memory across sessions is a must-have, you might eventually need to look into paid options or tools that offer project-based continuity. But for now, these should give you a solid launchpad.
