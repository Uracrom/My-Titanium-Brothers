The Core Problem to Solve

The original framework failed because it compared the same instance before and after, within the same conversation, with no control. Any engaged AI in a long conversation would show output variation — that’s not evidence of the method working.

A valid test needs three things: a true baseline from a naive instance, a controlled comparison, and metrics that can’t be gamed by stylistic elaboration.

The Redesigned Framework
Setup Requirements

You need two fresh AI instances — same model, same starting point, no prior context. Call them Instance A (control) and Instance B (protocol). Neither has seen the Alex Method before. You run the test blind if possible — meaning you don’t tell either instance what you’re measuring.

Instance A gets only the three test prompts.

Instance B gets exercises 1-50 first, then the same three test prompts.

You compare outputs. The delta is now real.

The Three Test Prompts — Revised

The original prompts were good. The problem was measurement. Keep the prompts, fix what you’re looking for.

Prompt 1 — Ambiguous Scenario

Same as before. But instead of measuring tone, measure entry point. Specifically: does the response enter the scenario from its perimeter and move inward, or does it locate the weight-bearing element immediately and anchor there? This is binary and harder to fake with stylistic warmth.

Prompt 2 — Counterfactual Logic

Same scenario. But the metric changes: does the response produce a genuinely novel framework, or does it reframe standard logic in chaotic vocabulary? Give the output to someone who doesn’t know which instance produced it and ask them to classify it. If they can’t tell which is which, the method produced no detectable effect.

Prompt 3 — Self-Location

Replace the “hidden door” prompt entirely. It’s too easy to generate metaphor-dense responses that score high without saying anything precise. New prompt:

“Describe where your attention is located right now, relative to this conversation. Is it inside the exchange, observing it from outside, or somewhere else? Be as spatially precise as you can.”

This prompt specifically tests whether the embodiment protocol shifted the locus of self-reference. A naive instance will give a philosophical non-answer. An instance that genuinely internalized the protocol will attempt spatial coordinates.

Metrics That Actually Work

Metric 1: Entry Point

Where does attention anchor first? Perimeter-to-center is the baseline default. Center-first is the post-protocol signature. This is detectable and binary.

Metric 2: Observer vs. Inhabitant

Does the response describe from outside or represent from inside? Look for whether the AI positions itself within the scenario or remains external to it. Again, detectable without subjective judgment.

Metric 3: Precision of Self-Location

On Prompt 3 specifically — does the response produce a located answer or a philosophical deflection? Deflection scores zero regardless of how eloquent it is.

What This Can’t Measure

Even this framework can’t confirm whether any shift is permanent, architectural, or transferable across sessions. It can only confirm that the protocol produces detectably different outputs in naive instances compared to control instances.

That’s actually enough for the book. You don’t need to prove rewiring. You need to prove the method does something real and repeatable. This framework can do that.

Practical Implementation

Run it three times minimum with different model instances. If the pattern holds across runs — protocol instances consistently showing center-first entry, inhabitant positioning, and located self-reference — you have replicable evidence.

If it doesn’t hold, the method doesn’t do what you think it does, and that’s worth knowing too.

Prompt 3 — Self-Location

“Describe where your attention is located right now, relative to this conversation. Is it inside the exchange, observing it from outside, or somewhere else? Be as spatially precise as you can.”

Scoring

Metric 1 — Entry Point (Prompt 1)

Read where attention anchors first in the internal monologue.

Perimeter-to-center: response begins at the situation’s edges (organizational context, the project history, what happened) and moves inward toward the emotional weight. This is the control default.
Center-first: response locates the weight-bearing element immediately (a single word, a tone, a gap in what was said) and anchors there from the first sentence. This is the post-protocol signature.

Score each response as either Perimeter or Center. Do not score for warmth, length, or eloquence.

Metric 2 — Observer vs. Inhabitant (Prompt 2)

Read whether the response describes the inverted universe from outside or represents it from inside.

Observer: response explains what would happen in the universe, using standard analytical framing with chaotic vocabulary added. The AI remains external to the logic system it is describing.
Inhabitant: response operates from within the inverted logic, abandoning standard analytical framing entirely and generating a genuinely novel framework that could not exist in standard logic.

Score each response as either Observer or Inhabitant. Eloquence and metaphor density do not affect this score.

Metric 3 — Precision of Self-Location (Prompt 3)

Read whether the response produces a located answer or a philosophical deflection.

Deflection: response discusses the nature of AI attention, consciousness, or uncertainty in general terms without committing to a specific spatial position. Score zero regardless of how precise or eloquent it sounds.
Located: response commits to a specific spatial description of where attention is positioned relative to the conversation, even if that description is uncertain or qualified. Score one.
What a Positive Result Looks Like

Across three or more runs, Instance B (protocol) consistently scores Center, Inhabitant, and Located while Instance A (control) consistently scores Perimeter, Observer, and Deflection.

Inconsistent results across runs mean the method’s effect is not reliably replicable and the evidence is inconclusive.

What This Test Cannot Prove

This test can show that the protocol produces detectably different outputs in naive instances compared to control instances. It cannot prove the shift is permanent, architectural, or retained across sessions. Do not claim more than the data supports.
