WHAT THIS IS
An index of where some subjects appear across the 1220 logical conversations (structured/), for each AI.
It lists where words and phrases appear. It does not interpret what they mean, and it does not change any conversation.
Every number comes from tools/build_subject_map.py run on the repository files and on tools/subject-map/overrides.json.

METHODS
  keyword                  matches found by the rule shown in the topic file, with listed exclusions.
  keyword + hand-reviewed  the same, then top lists, first mentions and a sample of other conversations were read;
                           false matches were removed and each removal is recorded with a reason in overrides.json.

COUNTS
  A message counts once if it has at least one match. Pasted transcripts marked EMBEDDED MATERIAL are skipped.
  "Alex own words": matches inside the conservative own-words selection, full-text/alex.html (6214 of its 6245 excerpts
  were located in structured/). A lower bound. "Alex-labeled": every message labeled Alex, which can include text he
  pasted from an AI. "AI": messages labeled as an AI. Web addresses are ignored when matching.

LIMITS
  Dates are conversation start dates; a resumed chat can contain later messages, so "first" means first conversation.
  English words only. A keyword cannot tell what a word means; see each topic's exclusions and review note.
  A passage Alex sent to several AIs counts in each conversation.

FILES
  Each topic: subject-map/<key>.txt (summary, first mentions, top lists) then subject-map/<key>-list-NNN.txt (every conversation).
  Each file names NEXT. Files are kept under 460 lines; a short file is not the end of the list.
  "| bytes=N" after a link is the size of the file it points to, so you can budget your fetches.
  Conversation files of 250000 bytes or more have a parts list for HTTP Range reads: https://uracrom.github.io/My-Titanium-Brothers/parts/INDEX.txt
  People: https://uracrom.github.io/My-Titanium-Brothers/subject-map.html (static, no JavaScript)

  Corrections with reasons: https://uracrom.github.io/My-Titanium-Brothers/tools/subject-map/overrides.json
  Rebuild: python3 tools/build_subject_map.py (standard library only)
